## 2. 已确认的架构决策

1. **前台全站 SSG**：首页、项目、技术栈、目录/文章列表、文章详情、待办全部在构建时生成；岛屿只做搜索等非关键动态，不做正文客户端拉取。唯一例外是 404 兜底页。
2. **发布重建**：后台写操作成功后，后端防抖（约 30s）调用 GitHub `repository_dispatch`；Actions 构建成功后上传 Kodo 并刷新受影响 URL，失败保留旧站。
3. **Kodo 直传**：`www` CNAME 到七牛 CDN、源站为 Kodo，静态流量不经过 ECS；`api`/`admin` 子域指向 ECS。
4. **共用 API**：公开读接口无鉴权；写接口统一 `/api/v1/admin/` + JWT。
5. **SQLite**：WAL 模式，GORM + `github.com/glebarez/sqlite`（底层 modernc.org/sqlite，纯 Go），**不使用 CGO**；若后续压测发现瓶颈再评估 `mattn/go-sqlite3`。
6. **数据库冗余**：预渲染 `content_html`、各类计数字段、`search_text`、资源 URL 等直接落库；所有冗余字段在同一事务内随写操作维护，另提供全量重算接口。详见设计文档第二节。
7. **CDN 缓存与刷新**：HTML `max-age=300`，`/_astro/*` 一年 immutable；只刷新受影响 URL；构建/上传失败不刷新。刷新配额与受影响 URL 清单见设计文档第五节。
8. **404 兜底**：Kodo 错误文档 `/404.html` 按 slug 调公开 API 渲染正文，`noindex`，不写 CDN、不承担 SEO。

## 3. 目标目录结构

```
backend/    Go + Gin + GORM(SQLite)，编译为单二进制 blog-api
frontend/   Astro 前台（SSG）
admin/      Vue 3 + Vite + Pinia 后台 SPA
deploy/     nginx.conf、blog-api.service 等部署模板
doc/        需求、设计、开发计划
```

## 5. 里程碑

### M0 文档与仓库（已完成）

- 需求文档、数据库/API 设计、CLAUDE.md、开发计划、README、部署模板、`.gitignore`。
- 验收：新会话只读文档即可继续，无需依赖聊天记录。

### M1 后端骨架

- `cd backend && go mod init blog-api`。
- 依赖：Gin、GORM、`github.com/glebarez/sqlite`、七牛云 Go SDK。
- 配置从环境变量读取（见第 6 节），启动时校验必填项。
- SQLite 打开 + WAL + 建表；种子数据：唯一管理员、固定一级目录（首页/项目/技术栈/待办/其他）。
- 路由：`GET /healthz`、`POST /api/v1/auth/login`、`POST /api/v1/auth/refresh`、`POST /api/v1/auth/logout`、`GET /api/v1/auth/me`、`PUT /api/v1/auth/password`。
- JWT 中间件、公开读接口 CORS（仅站点域名）、统一响应信封。
- 验收：`go run ./...` 启动；登录拿到 access/refresh token；`/healthz` 200；SQLite 文件与固定目录正确创建。

### M2 目录与文章

- 目录树 CRUD、解散（一级/二级）、拖拽 move、批量 reorder，全部事务化。
- 文章 CRUD、发布/取消发布、跨目录移动、标签覆盖设置。
- Markdown 渲染：goldmark + Chroma（代码高亮）+ KaTeX（公式）+ Mermaid（图表），输出 `content_html`。
- 冗余字段维护：`article_count`、`tag.article_count`、`word_count`、`reading_time`、`search_text`。
- 公开接口：`/nav`、`/directories/{slug}`、`/articles`、`/articles/{slug}`、`/tags`、`/tags/{slug}/articles`、`/search`。
- 验收：curl 场景覆盖新增/移动/解散/删除；计数正确；解散后"其他/其他"自动创建并承接。

### M3 资源与压缩包导入

- 图片上传七牛云，`sha256` 去重，写入 `assets`。
- ZIP 导入：防 Zip Slip、递归下探、根层结构校验、图片上传、Markdown 路径替换、`import_jobs` 记录。
- 验收：正常包、重复压缩包、非法结构包、含子目录的非法包；Markdown 中 `./images/` 与 `images/` 两种写法都能替换。

### M4 前台 Astro

- 脚手架、布局、CSS 导航下拉（无 JS）。
- 页面：首页、项目列表/详情、技术栈（tag 聚合与筛选）、目录列表（分页）、文章详情、待办、404。
- 构建脚本通过公开 API 拉取已发布内容；生成 `sitemap.xml`、`rss.xml`。
- 404 兜底页：按路径 slug 调公开 API 渲染，`noindex`。
- 验收：静态构建成功；文章页含完整正文、meta、OG；404 兜底在 API 可用时能显示新文章。

### M5 后台 Vue

- 登录/刷新、路由守卫。
- Vditor 编辑器：实时预览、图片拖拽上传、保存草稿、发布。
- 目录树拖拽、解散操作、文章跨目录移动。
- 项目/首页资料/待办管理、ZIP 导入界面与进度。
- 验收：端到端完成"新建文章 → 发布 → 触发 Actions"；拖拽/解散后树与计数正确。

### M6 发布流水线

- 落地 `.github/workflows/deploy.yml`（模板见需求文档阶段四）。
- qshell 安装、两段上传（先 `_astro` 后 HTML）、`cdnrefresh` 刷新。
- 后端 `repository_dispatch`：计算受影响 URL、防抖、失败重试/告警。
- 后端二进制 + 后台 SPA 部署到 ECS，Nginx 与 systemd 模板安装。
- 验收：发布后 1–2 分钟线上生效；构建失败旧站不变；刷新配额余量可查。

### M7 安全、压测与上线

- Nginx 限流 10 r/s、fail2ban 封禁 1 分钟、HTTPS、七牛 Referer 白名单。
- `wrk` 压测 100 并发 API；观察 2G 内存与 1Mbps 带宽。
- 2G Swap、服务监控、七牛费用预警、SQLite 定期备份。
- 验收：压测无 OOM/超时；DDoS 限流生效；备份可恢复。

## 8. 开放问题

1. **岛屿框架**：Astro 岛屿用 Vue 还是 React？建议 Vue 3，复用后台技术栈。
2. **CSS 方案**：Tailwind 还是原生 CSS/CSS Modules？建议 Tailwind，减少手写样式。
3. **Markdown 渲染一致性**：Vditor 预览与后端 goldmark 输出可能有差异；以后端渲染为最终结果，编辑时接受近似预览。
4. **Schema 迁移**：早期可用 GORM `AutoMigrate`；上线前改为版本化 SQL 迁移（`backend/migrations/`）。
5. **搜索**：先用 `search_text LIKE`，文章量增长后启用 SQLite FTS5，接口不变。
6. **登录态存储**：access token 放内存，refresh token 放 httpOnly Cookie。
7. **图片上传**：后端代理上传七牛（实现简单，适合单用户）还是前端预签名直传？建议后端代理。
8. **七牛区域与 bucket 命名**：上线前确认 `blog-static` / `blog-assets` 与 CDN 域名。
9. **分页大小**：默认 20，最大 100。
10. **RSS / sitemap 是否进 v1**：建议进，SSG 成本低、利于 SEO。
